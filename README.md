# phone_transfer_analysis
Учебный pet-проект системного аналитика: разбор функции «Перевод по номеру телефона»

## Описание проекта
В проекте разобрана существующая функция перевода денежных средств по номеру телефона: описан пользовательский сценарий, бизнес-правила, интеграция с СБП, спроектированы диаграммы, модель данных и учебный API-контракт

## Цель
Показать навыки системного аналитика:
- анализ пользовательского сценария и бизнес-правил
- моделирование процесса в BPMN
- проектирование взаимодействия систем в UML Sequence
- проектирование модели данных в ERD
- описание API в OpenAPI
- формализация функциональных и нефункциональных требований
