## Бизнес-контекст

## 1. Описание функции

Перевод по номеру телефона - функция в мобильном приложении банка, позволяющая клиенту перевести денежные средства на счет другого физического лица по номеру телефона или через СБП.

## 2. Бизнес-проблема

Без перевода по номеру телефона клиенту необходимо:
- запросить у получателя номер карты или счета
- вручную вводить банковские данные
- проверять правильность введенных данных

Это влечет увеличение времени операции и вероятность ошибки: клиент может неверно ввести данные или вовсе отказаться из-за сложности сценария.

## 3. Бизнес-цель

Функция направлена на:
- сокращение кол-ва действий при переводе
- снижение кол-ва ошибок при вводе реквизитов
- предоставление возможности перевода по минимальным данным получателя - номеру телефона
- поддержку переводов как внутри банка, так и клиентам других банков
- повышение удержания клиентов и удобство использования приложения

## 4. Пользователи функции

| Актор | Роль |
| --- | --- |
| Отправитель | Клиент банка N, инициирующий перевод |
| Получатель | Физ. лицо, которому переводят средства |
| Мобильное приложение | Канал, через который Отправитель формирует и подтверждает перевод |
| Backend банка N | Проверяет данные, счет, лимиты и управляет операцией |
| СБП | Внешняя система, необходимая для перевода в другие банки |
| Банк получателя | Банк, в котором обслуживается Получатель, если он не клиент банка N |

## 5. Основной пользовательский сценарий

1. Клиент (Отправитель) открывает мобильное приложение банка N
2. Переходит в раздел "Платежи"
3. Выбирает "Перевод по номеру телефона"
4. Вводит номер телефона Получателя
5. Указывает сумму перевода
6. Выбирает счет/карту для списания
7. Проверяет сумму/комиссию/допустимый лимит
8. Подтверждает операцию
9. Получает уведомление о результате перевода

## 6. Бизнес-правила

- перевод возможен только при наличии достаточно кол-ва средств на выбранном счете для списания
- перед списанием средств операция должна быть подтверждена клиентом
- для переводов в другие банки могут учитываться лимиты и комиссия
- система должна однозначно идентифицировать операцию и отображать ее статус
