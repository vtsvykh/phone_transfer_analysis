## Функциональные требования

| ID | Требование | Приоритет |
| --- | --- | --- |
| FR-1 | Система должна позволять пользователю ввести номер телефона получателя | Must have |
| FR-2 | Система должна проверять корректность указанного номера телефона | Must have |
| FR-3 | Система должна позволять пользователю указать сумму перевода | Must have |
| FR-4 | Система должна позволять выбрать счет или карту для списания | Must have |
| FR-5 | Система должна отображать сумму, доступный остаток и комиссию до подтверждения | Must have |
| FR-6 | Система должна требовать подтверждение операции пользователем | Must have |
| FR-7 | Система должна проверять достаточность средств на счете списания | Must have |
| FR-8 | Система должна проверять месячный лимит переводов | Must have |
| FR-9 | Система должна определять является ли получатель клиентом банка N | Must have |
| FR-10 | Если получатель является клиентом банка N, то она должна осуществлять внутренний перевод | Must have |
| FR-11 | Если получатель - клиент другого банка, система должна инициировать перевод по СБП | Must have |
| FR-12 | Система должна передавать в СБП данные, необходимые для перевода | Must have |
| FR-13 | Система должна отображать статусы, возвращаемые СБП | Must have |
| FR-14 | Система должна отображать статус перевода с учетом статуса СБП | Must have |
| FR-15 | Система должна предотвращать списание при повторной отправке запроса | Must have |
| FR-16 | Система должна создавать запись операции с уникальным идентификатором | Must have |
| FR-17 | Система должна отображать статус перевода | Must have |
| FR-18 | Система должна уведомлять пользователя о результате операции | Should have |
| FR-19 | Система должна возвращать понятную причину при отклонении перевода | Must have |
