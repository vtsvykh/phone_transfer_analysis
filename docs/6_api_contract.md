## API-контракт

1. Назначение документа

Документ описывает учебный API-контракт взаимодействия мобильного приложения с backend-сервисом переводов по номеру телефона

API позволяет:

- предварительно рассчитать условия перевода
- создать перевод по номеру телефона
- получить статус перевода

2. Общие правила

- Формат обмена данными: JSON
- Спецификация: OpenAPI 3.0
- Базовый путь: `/api/v1`
- Кодировка: UTF-8
- Аутентификация: предполагается, что пользователь авторизован в мобильном приложении
- Идентификаторы операций и счетов передаются в виде строк

3. Операции API

| Операция | Метод | Путь | Назначение |
|---|---|---|---|
| Предварительный расчёт | POST | `/transfer-preview` | Проверить данные и получить условия перевода |
| Создание перевода | POST | `/transfers` | Создать и инициировать перевод |
| Получение статуса | GET | `/transfers/{transferId}` | Получить актуальный статус перевода |

4. Предварительный расчёт перевода

  4.1. Зачем нужен

  Перед подтверждением пользователь должен видеть:
  
  - сумму перевода
  - комиссию
  - счёт списания
  - доступный остаток
  - доступный лимит

Поэтому мобильное приложение сначала вызывает предварительный расчёт, а не сразу создаёт перевод

  4.2. Запрос

```http
POST /api/v1/transfer-preview
Content-Type: application/json
```

```json
{
  "recipientPhone": "+79001234567",
  "amount": 1500.00,
  "sourceAccountId": "acc-123456"
}
```

  4.3. Успешный ответ

```http
200 OK
```

```json
{
  "recipientPhone": "+79001234567",
  "recipientBankId": "bank-001",
  "transferType": "SBP",
  "amount": 1500.00,
  "commission": 0.00,
  "sourceAccountId": "acc-123456",
  "availableBalance": 25000.00,
  "availableLimit": 100000.00
}
```

  4.4. Ошибки

| Код | Ситуация | Причина |
|---|---|---|
| 400 | Некорректный номер телефона | Нарушен формат номера |
| 400 | Некорректная сумма | Сумма отсутствует, отрицательная или равна нулю |
| 404 | Счёт не найден | Указан несуществующий `sourceAccountId` |
| 502 | Ошибка внешней системы | Сервис лимитов или СБП недоступен |

5. Создание перевода

  5.1. Зачем нужен

После того как пользователь ознакомился с условиями и подтвердил операцию, мобильное приложение отправляет запрос на создание перевода

  5.2. Запрос

```http
POST /api/v1/transfers
Content-Type: application/json
Idempotency-Key: 7f9c24e2-8d1a-4f7e-b8f1-9a2b3c4d5e6f
```

```json
{
  "recipientPhone": "+79001234567",
  "amount": 1500.00,
  "sourceAccountId": "acc-123456",
  "comment": "За обед"
}
```

  5.3. Поля запроса

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `recipientPhone` | string | Да | Номер телефона получателя |
| `amount` | number | Да | Сумма перевода |
| `sourceAccountId` | string | Да | Идентификатор счёта или карты списания |
| `comment` | string | Нет | Комментарий к переводу |

  5.4. Успешный ответ

```http
201 Created
```

```json
{
  "transferId": "tr-987654",
  "status": "PROCESSING",
  "transferType": "SBP",
  "amount": 1500.00,
  "commission": 0.00,
  "createdAt": "2026-11-02T11:30:00Z"
}
```

  5.5. Ошибки

| Код | Ситуация | Причина |
|---|---|---|
| 400 | Некорректный запрос | Ошибка валидации полей запроса |
| 401 | Пользователь не авторизован | Отсутствует или недействительна авторизация |
| 404 | Счёт не найден | Указан несуществующий счёт списания |
| 409 | Недостаточно средств | Баланс счёта меньше суммы перевода |
| 409 | Превышен лимит | Исчерпан доступный лимит переводов |
| 409 | Повторный запрос | Запрос с таким `Idempotency-Key` уже обработан |
| 502 | Ошибка СБП | Внешняя система недоступна или вернула ошибку |

6. Получение статуса перевода

  6.1. Зачем нужен

Перевод может обрабатываться не мгновенно, особенно если он выполняется через СБП. Поэтому приложение может запросить актуальный статус операции

  6.2. Запрос

```http
GET /api/v1/transfers/tr-987654
```

  6.3. Успешный ответ

```http
200 OK
```

```json
{
  "transferId": "tr-987654",
  "status": "COMPLETED",
  "transferType": "SBP",
  "amount": 1500.00,
  "commission": 0.00,
  "createdAt": "2026-11-02T11:30:00Z",
  "completedAt": "2026-11-02T11:30:12Z",
  "statusReason": null
}
```

  6.4. Возможные статусы

| Статус | Значение |
|---|---|
| `CREATED` | Перевод создан, но ещё не подтверждён или не передан в обработку |
| `PROCESSING` | Перевод обрабатывается |
| `COMPLETED` | Перевод успешно выполнен |
| `DECLINED` | Перевод отклонён по бизнес-причине |
| `FAILED` | Перевод не выполнен из-за технической или внешней ошибки |

  6.5. Ошибки

| Код | Ситуация | Причина |
|---|---|---|
| 404 | Перевод не найден | Указан несуществующий `transferId` |
| 401 | Пользователь не авторизован | Нет доступа к операции |

7. Коды ответов

| Код | Название | Когда используется |
|---|---|---|
| 200 | OK | Запрос успешно выполнен |
| 201 | Created | Перевод успешно создан |
| 400 | Bad Request | Некорректные данные в запросе |
| 401 | Unauthorized | Пользователь не авторизован |
| 404 | Not Found | Счёт или перевод не найдены |
| 409 | Conflict | Недостаточно средств, превышен лимит или повторный запрос |
| 500 | Internal Server Error | Внутренняя ошибка backend |
| 502 | Bad Gateway | Ошибка или недоступность внешней системы, например СБП |

8. Формат ошибок

Все ошибки рекомендуется возвращать в едином формате:

```json
{
  "errorCode": "INSUFFICIENT_FUNDS",
  "message": "Недостаточно средств на выбранном счёте",
  "details": {
    "sourceAccountId": "acc-123456",
    "availableBalance": 1000.00,
    "requestedAmount": 1500.00
  }
}
```
